Si l’autorisation ne s’affiche pas

Le fichier HTML ouvert directement depuis Téléchargements (adresse commençant par file://) peut être bloqué par Android/Chrome. Dans ce cas, ce n’est pas un réglage de sensibilité : il faut ouvrir la page depuis une adresse HTTPS sécurisée, puis autoriser le micro dans les permissions du site.

  1. Ouvre la page dans Chrome, pas dans l’aperçu du gestionnaire de fichiers.
  2. Si Chrome affiche une erreur de contexte sécurisé, héberge la page sur un site HTTPS de confiance.
  3. Dans Chrome : menu ⋮ → Paramètres → Paramètres des sites → Microphone, puis autorise le site concerné.
  4. Recharge la page et appuie de nouveau sur « Activer le micro ».

Le navigateur peut afficher une permission système Android supplémentaire. Ne choisis pas « Bloquer » si tu souhaites utiliser le moniteur.
